Images can appear as post covers, in page/post content, as timeline thumbnails, or in social-sharing previews. The website crops them differently in each location.

## Upload, reuse, or replace a photo

1. Open **Cover Image**, **Open Graph Image**, a body **Image** block, or a milestone's **Image** field.
2. Use the upload control to choose a file, or the selection/browse control to reuse an available asset.
3. Wait until the upload finishes and the image appears.
4. To replace a photo, open the field's image actions and choose a new upload or existing asset.
5. Preview all places where the image will appear, then publish the document.

The current Studio does not enable an Unsplash source. Upload your photo or reuse an asset offered by the image picker. Use images the pantry has permission to publish.

## Crop and choose the focal point

Open the image editing control to adjust **Crop** and **Hotspot** where offered. Crop trims the image; hotspot marks the area that should stay visible when the website chooses a different crop.

For a volunteer-group photo, put the hotspot over the faces and leave enough space around them. Avoid placing important words near an image's edge. Preview the cover, post listing, and homepage if the photo belongs to the latest post. Body images display in a wide frame; timeline thumbnails are small squares.

*The rectangle handles change the crop. The hotspot's circle/oval marks the area to keep visible in different image shapes. Open this editor using the image's edit control.*

## Captions and alt text

Body image blocks include:

- **Caption:** visible text below the photo. For example, “Volunteers preparing food-drive donations.”
- **Alt text:** a description for people who use screen readers. For example, “Three pantry volunteers packing donated groceries into boxes.”

Alt text and captions have different purposes. Fill in **Alt text** for meaningful body images; a caption is not used automatically as alt text by the current website. Do not start every description with “image of”. Describe what matters to the surrounding story.

The current **Cover Image**, **Open Graph Image**, and milestone **Image** fields do not expose separate caption or alt-text inputs. Milestone thumbnails use the milestone title as their description. Ask the developer if those fields need additional accessibility controls.

## Removing images safely

Removing an image from a field or deleting a body image block changes that document. Deleting the uploaded asset itself can affect other documents that reuse it. Review any usage/reference information and avoid deleting shared assets just to replace one photo.

A post's **Cover Image** is required. Choose a replacement before publishing a post that needs a new cover.

## Check the result

Wait for saving, preview the crops, read captions, and publish when ready. Check the public post list and full post. If the image is missing or cropped poorly, see [troubleshooting](troubleshooting.md#an-image-is-missing-or-cropped-badly).
