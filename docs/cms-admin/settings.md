Home and Settings are shared documents. Their published changes can affect the entire website, so check more than one page after updating them.

## Home: site title and description

1. Open **Home** in the content tool.
2. Edit **Title** to change the default website title used in browser/search metadata. Individual pages and posts add their own titles to the site name. Title is required.
3. Edit **Description** to change the default search description. Description is required; write a concise explanation of the pantry and who it serves.
4. Publish, then inspect the public website's browser title. Search engines may take time to revisit the site and may choose a different search snippet.

These fields do not replace the fixed heading, mission, or other paragraphs on the public homepage. The homepage's latest-update photo and summary come from the latest dated published post.

**Posts for the website** is a reference list retained from an earlier setup. It currently does not select posts on the public homepage or `/posts`. Adding, removing, or reordering references there does not control either listing. Removing a reference does not delete the post.

## Settings: footer text

1. Open **Settings** in the content tool, or use **Open Settings** above this guide.
2. Edit **Footer Info**. This text appears at the bottom of website pages.
3. Use the available text formatting and link controls. For example, add a short confirmed pantry message and a link to more information.
4. Publish and check the footer on the homepage and a post page. If Footer Info is empty, no footer message is shown.

*Edit the text inside Footer Info. The toolbar becomes available when you place the cursor in the text editor. The guide link below the field returns here.*

## Settings: social-sharing image

**Open Graph Image** supplies the default preview image when the website is shared. Upload or choose an image, then check its crop and hotspot. A wide image works best; the website produces a sharing crop around 1200 × 627 pixels.

Individual posts supply their own **Cover Image** for sharing. A social network can retain an old preview after you change the image; its preview does not always refresh immediately. This field does not change the website logo and does not guarantee that a search engine will display an image.

## Settings: menu references

**Menu Item list** is currently unused by the website's main navigation. It can store references to Home, Pages, and Posts, but publishing or reordering that list does not alter the visible menu. Ask the developer for navigation changes.

## Verify and get help

Review shared changes carefully before publishing. Home and Settings cannot be duplicated through the normal document action; keep using the existing shared documents.

If you expected to change the logo, opening hours, contact details, About text, or donation link, consult [What can I change?](content-map.md). Those updates currently require the maintainer.
