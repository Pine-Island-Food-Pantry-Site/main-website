A post is an announcement or story. Published posts appear on `/posts`, with newer dates first. The newest dated post also supplies the photo and summary in the homepage's latest-update section.

## Create the announcement

1. Open **Post** in the content tool and use its create-document control, or select **Create a post** above this guide.
2. Enter a **Title**, such as “Holiday Food Drive”. This field is required.
3. In **Slug**, select **Generate** to create the website address from the title. Check it before publishing. `holiday-food-drive` gives `/posts/holiday-food-drive`. The slug is required and must be unique among posts.
4. Write an **Overview**: a short, useful summary, such as “Bring shelf-stable food to our holiday drive on Saturday. See drop-off details and the items we need.” This field is required.
5. Add a **Cover Image**. This field is required. Choose a photo that works in a cropped preview and read [photo guidance](images.md).
6. Set **Publish Date** to the date/time you want used for post ordering. Use the date control's displayed timezone when entering it.
7. Add optional **Tags**, such as `food-drive` or `volunteer`. Use the tags input to enter and confirm each tag. Tags appear on the post; they do not control the current website search.
8. Write the full announcement in **Post Description**. Include confirmed dates, times, location, who the event is for, and how readers can help. Add links, body images, or a timeline using the available controls.

## Understand the summary and date

The **Overview** appears in the public post listing, provides the post's search-engine description, and is searched by the website's post search. For the latest post, it also appears on the homepage. The full **Post Description** supplies the story on the individual post page.

Aim for a concise overview, roughly one or two short sentences. Studio does not currently enforce a 155-character text limit.

**Publish Date** sorts posts; entering a future date does not delay publication. If you press **Publish**, a future-dated post can become the latest post immediately. The field is optional in Studio, but setting it makes ordering predictable. See [publishing](publishing.md) for any scheduling controls available to your account.

## Review, publish, and verify

1. Wait until the draft has saved and resolve any validation errors.
2. Review the [before-publishing checklist](checklist.md).
3. Preview the post using **Presentation** if available, then select **Publish** when you intend to make it public.
4. Open `/posts` outside draft preview. Check the title, summary, image, and link to the full post.
5. If it is the newest dated post, also check the latest-update section on the public homepage.

If Publish is disabled or the update does not appear, see [troubleshooting](troubleshooting.md). Learn to maintain published posts in [Edit and manage posts](manage-posts.md).
