Use the text toolbar shown in the field you are editing. Different fields support different controls.

## Choose the right text field

- **Home → Description:** short site summary with bold, italic, and links.
- **Page/Post → Overview:** short summary with bold and italic. Links and lists are not enabled here.
- **Page → Body** and **Post → Post Description:** main content with available formatting, lists, links, image blocks, and timeline blocks. These fields do not offer heading styles in the current setup.
- **Settings → Footer Info:** text, links, lists, and available heading styles. Images and timelines are not enabled in this field.
- **Milestone → Description:** plain text, rather than the rich-text editor.

## Write clear text

1. Click inside the text field and enter a paragraph.
2. Start a new paragraph with Enter. Use short paragraphs for event details and instructions.
3. Select text and use **Bold** or **Italic** when those controls are available.
4. Use a bullet or numbered list when the field offers list controls. Preview to check the result.

If text pasted from a document brings unwanted formatting, undo and paste as plain text using your browser's paste-without-formatting command. Review spacing and punctuation after pasting.

## Add or change a link

1. Select meaningful text, such as “See drop-off details”.
2. Use the link control and enter the destination in **Url**.
3. Confirm the link, then test it in preview or on the published page.

For another website, enter its complete `https://` address. For a page on this website, use its complete address if Studio's URL validation rejects a relative address. Link availability depends on the field; an Overview cannot contain a link.

To change a link, select its text and reopen the link control. Use the control's remove action to unlink text. Prefer descriptive link labels to “click here”.

## Insert and organise blocks

In **Body** or **Post Description**, use the insert/add control to choose **Image** or **Timeline** where available. Open a block to edit its fields. Use the block's drag handle or available movement controls to change its position. Removing a body image block removes it from this document; it does not necessarily delete the uploaded asset.

See [photos](images.md) for captions and alt text and [timelines](timelines.md) for milestone fields.

## Check the result

Preview paragraph breaks, emphasis, list order, links, and block positions. For a food-drive post, readers should easily find what to bring, when to arrive, and where to go. Use [Before you publish](checklist.md) for the final review.
