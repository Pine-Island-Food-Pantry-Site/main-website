A timeline block displays groups of milestones inside a page or post. Each block allows at most two groups. On a wide screen, the groups appear next to one another; on a narrow screen, they stack.

## Add groups and milestones

1. Open a Page's **Body** or a Post's **Post Description**.
2. Use the insert/add control and choose **Timeline**.
3. Open the timeline's **Items** and add an **Item**. Give the group a **Title**, such as “Pantry milestones”.
4. Inside the group, open **Milestones** and add a **Milestone**.
5. Fill in the milestone's required **Title**. Add an optional plain-text **Description**, an **Image**, and **Tags**.
6. Open the required **Duration** object and use its date input if you need to record a date. Read the date limitation below before relying on a visible year.
7. Add more milestones and use their available movement controls to arrange them in the order readers should see them.
8. Add a second group if needed. A third group is blocked by validation; use another timeline block if you need more groups.

For example, a group could contain “Food drive launched” and “First volunteer packing day”, each with a short explanation and a thumbnail.

## Current date limitation

The current editor records one date inside **Duration**, but the website's timeline year display is not connected to that date correctly. Entering it does not reliably produce the intended visible year. A timeline can show incomplete date text such as “Now”.

If accurate timeline years are important, ask the website maintainer to correct the display before publishing. Include essential dates in the milestone's **Description** and check preview, rather than depending on the year label.

## Review and publish

Check group titles, milestone order, descriptions, tags, and cropped thumbnails. Milestone titles and Duration are required; resolve any validation errors. Then publish the page or post and check the public result at different screen sizes.

To remove a milestone or group, use its item menu and check that you are removing the intended item. The change stays in the draft until you publish. See [recovery](collaboration.md#review-and-restore-a-revision) if you need to undo saved changes.
