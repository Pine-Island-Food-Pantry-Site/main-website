Use this map to choose the right place for an update. Some website sections are maintained by the developer rather than through Studio.

## Content you can update

- **Announcements and news:** create or edit a **Post**. Posts appear at `/posts` and each post has its own address under `/posts/`.
- **Latest update on the homepage:** the website uses the cover photo and overview of the published post with the latest **Publish Date**. Editing that post changes this section.
- **Custom pages:** create or edit a **Page**. A page has an address such as `/food-drive-details`. You must also provide a link so visitors can find it.
- **Default site title and search description:** edit **Home → Title** and **Home → Description**. These affect browser/search metadata, rather than replacing the fixed homepage heading and paragraphs.
- **Footer text across the website:** edit **Settings → Footer Info**.
- **Default social-sharing image:** edit **Settings → Open Graph Image**. Individual posts use their cover image for sharing.

## Changes that need a developer

Contact your website maintainer for changes to the fixed homepage copy, About page, board-member list, Contact details or form, pantry hours and address, logo, map, donation destination, main navigation, and page design.

The **Home → Posts for the website** list currently does not select which posts appear on the website. The **Settings → Menu Item list** currently does not change the navigation. Those fields are labelled accordingly in Studio. Publishing them does not connect these features.

Creating a Page with the slug `about` or `contact` does not replace those existing website pages. Read [page addresses](pages.md#choose-a-page-address) before creating a page.

## Useful words

- **Document:** one saved item in Studio, such as a post, a page, or the shared Settings document.
- **Field:** one part of a document, such as its title or cover image.
- **Draft:** saved work that has not been published. Changes to a published item become a new draft until you publish again.
- **Publish:** make the document's current content available to the public website.
- **Slug:** the readable part of an address, such as `holiday-food-drive` in `/posts/holiday-food-drive`.
- **Reference:** a connection to another saved document. Removing a reference removes the connection, not the original document.
- **Asset:** an uploaded image that can be reused in more than one document.
- **Overview:** a short summary used in listings or search descriptions. It is separate from the full story.

## Confirm you chose the right place

For example, a new food-drive announcement belongs in **Post**. A change to the pantry's phone number requires the website maintainer. A new message at the bottom of every page belongs in **Settings → Footer Info**.

If you cannot find a field matching your requested change, check [troubleshooting](troubleshooting.md) before changing unrelated content.
