A Page adds content at its own website address. It does not automatically add a navigation link or change the fixed About and Contact pages.

## Create or edit a page

1. Open **Page** in the content tool. Select an existing page to edit, or use its create-document control.
2. Enter the required **Title**, such as “Food Drive Details”.
3. Generate and check the required **Slug**. The slug `food-drive-details` gives the address `/food-drive-details`.
4. Write the required **Overview**. This appears below the page title and supplies its search-engine description. Keep it short and helpful.
5. Write the main content in **Body**. Use the available text controls, links, images, or timelines. See [formatting](formatting.md).
6. Review and publish using the [publishing guide](publishing.md).

## Choose a page address

Use a short, descriptive slug with words separated by hyphens. Avoid changing it after publication unless you also update links and arrange redirects for old addresses.

Do not use existing application routes: `about`, `contact`, `posts`, `studio`, or `api`. Do not reuse another page's slug. A Page with the slug `about` will not replace the website's fixed About page.

## Help visitors find the page

Publishing makes the page available at its address. It does not automatically put it in the main menu or on the post listing.

For example, link to `/food-drive-details` from a relevant post. In the editor's URL control, use the full website address if a relative address is rejected. To add a main-navigation link, contact the developer; **Settings → Menu Item list** currently does not change the navigation.

## Verify the result

Open the page's address outside draft preview. Check its title, overview, body, images, and links. Then follow the link from the post or page where you added it.

If the address shows an unexpected existing page or a page-not-found message, check the slug and publication status and read [troubleshooting](troubleshooting.md).
