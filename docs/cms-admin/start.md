The CMS is the place where you update website content. Its editing interface is called **Studio**. You can save work as a draft, review it, and publish when it is ready.

## Sign in and find your way around

1. Open your website and add `/studio` to its address.
2. Sign in using the account invited to the pantry's Sanity project. If access is refused, contact the person who gave you access.
3. Open the content tool in the top navigation. It may be labelled **Structure** or **Desk**. Its content list contains **Home**, **Settings**, **Page**, and **Post**.
4. Select a content type, then select an existing document. Use Studio's search to find a document by title.
5. Select **Help & Guide** whenever you need instructions. Search this guide for a task, such as “upload a photo” or “change the footer”.

On a small screen, select **Browse all 13 guides** to open the article list. Choosing an article closes the list so you can read the instructions.

**Home** and **Settings** each open one shared document. **Page** and **Post** can contain many documents. A post is usually the right choice for a food drive, event announcement, or pantry update.

## Make your first update

1. Find a post you have been asked to update.
2. Change the relevant text in **Post Description**. Leave the **Slug** alone when the address should stay the same.
3. Wait for Studio to finish saving. A saved draft is not yet the public version.
4. Review the change and use the [publishing guide](publishing.md) to preview and publish it.
5. Open `/posts` on the public website and check the post.

For example, you can add a confirmed food-drive drop-off time to an existing announcement, then check that the new time appears on its public page.

## Other Studio tools

- **Presentation** shows the website layout with draft/published perspectives and editing controls for CMS content. Read the [preview guidance](publishing.md#preview-your-changes).
- **Vision** is a query tool for developers. Everyday content updates use the content editor.
- Extra collaboration or scheduling controls may appear depending on your account and subscription. See [collaboration and access](collaboration.md).
